# Workspace instructions

- Before finishing every task, stop all local development, preview, and test servers for this project, including servers left running from earlier turns.
- Verify that their listening ports have closed before the final response. Keep a server running only if the user explicitly requests it.
- Preserve unrelated application and operating-system services.

## Design preference

- Always prioritize simplicity over detail and keep text to a minimum. Use restrained industrial styling, clear spatial layouts, readable mechanics, and responsive first-person movement.
- Describe the design in its own terms. Keep named external game references out of committed documents, source comments, and commit messages.
- Favor sparse game menus with clear selection states over web-style cards, dashboards, and decorative controls.
- Favor edge-to-edge scenes over decorative borders or frames. Keep sound controls off the title screen.
