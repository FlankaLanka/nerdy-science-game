# Station and learning design

The current design is specified in [Asterion: an exploratory circuits lesson](research/station-design.md). It includes a cited research synthesis, knowledge graph, equipment requirements, five-component evaluation, state transitions, numerical assumptions and playtest scripts.

Eight investigations occupy a connected station with two loops and a central hub. The commissioning graph preserves prerequisites while the physical deck permits exploration. The opening lighting repair releases the first bulkhead; the remaining equipment can be inspected before its upstream systems are ready.

Testing is immediate. A prediction, hypothesis, written note or selected explanation is never a completion requirement. Guidance explains the current observation. Some investigations ask for an explicit controlled comparison, shown before testing; successful physical measurements enable Commission system. The last repair asks the player to construct independent paths without supplied wiring.

Every system has persistent visual feedback. The station contains no combat, oxygen countdown, consumable inventory or death penalty. Experiments can be repeated without penalty. Completed repairs have separate practice state so exploration cannot erase commissioning evidence.
