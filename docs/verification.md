# Lighthouse baseline verification

The current lighthouse source, survey map, geometry fixes, camera waypoint, and radio rescue flow are preserved in the baseline commit before the spaceship redesign.

Run `npm test`, `npm run build`, and `npm run test:browser`. The scripts in `scripts/` regenerate visual reviews when needed. Generated screenshots, old measured reports, duplicate source downloads, and unused decorative assets are excluded from the maintained repository. Historical verification is available in Git history.
